# Security Policy

## Reporting a Vulnerability

The security of Styleprobe and its users is important to us.

If you discover a security vulnerability, please report it responsibly.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use GitHub's private vulnerability reporting feature:

[Report a vulnerability](https://github.com/spidervirus/styleprobe/security/advisories/new)

If private vulnerability reporting is unavailable, contact the repository maintainer privately through GitHub.

## What to Include

Please provide as much information as possible:

- Description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact and affected components.
- Proof of concept, screenshots, or logs, if available.
- Suggested mitigation, if known.

## Response Process

We will aim to:

1. Acknowledge your report within 72 hours.
2. Investigate and assess the reported vulnerability.
3. Work on a fix and coordinate responsible disclosure.
4. Publish a security advisory when appropriate.

Please allow reasonable time for investigation and remediation before publicly disclosing a vulnerability.

## Supported Versions

Security fixes are primarily provided for the latest version of Styleprobe.

## Scope

Areas of particular interest include:

- Server-Side Request Forgery (SSRF).
- DNS rebinding and redirect validation bypasses.
- Arbitrary file access or code execution.
- Browser automation and crawling vulnerabilities.
- Dependency vulnerabilities.
- Exposure of sensitive information.
