# Styleprobe — Usage Examples & Integration Guide

`styleprobe` extracts complete visual design systems, dual-theme palettes, typography scales, SVG brand assets, and responsive cross-viewport behavior from any live URL for AI coding agents (**Claude Code, Cursor, Antigravity, Copilot, Codex**).

## 1. CLI Quick Start

Run `styleprobe` directly without installation using `npx`:

```bash
# Print markdown design system summary to terminal
npx styleprobe https://linear.app

# Output directly to a file
npx styleprobe https://linear.app -o DESIGN.md

# Inspect with headless browser visible (debugging)
npx styleprobe https://linear.app --headless false
```

## 2. AI Coding Agent Instruction Generation

AI coding agents often invent generic styles, unlisted web fonts, and random hex colors. `styleprobe` generates targeted agent instruction files containing exact design tokens, layout rules, and **strict negative constraints** ("styles AI agents must NOT invent").

### Claude Code (`CLAUDE.md`)
Generates a structured `CLAUDE.md` in the project root:

```bash
npx styleprobe https://supabase.com -f claude -o CLAUDE.md
```

**Generated sections:**
1. **Which Colors to Use**: Dual-theme canvas background, elevated cards, and primary accent variables.
2. **Fonts & Typography Scales**: Heading and body sizes, weights, and line heights.
3. **How to Structure Layouts**: Max-width containers, section padding scales, and grid structures.
4. **Component Styles to Reuse**: Buttons, cards, and input controls.
5. **How Responsive Behavior Works**: Breakpoints and mobile navigation collapse rules.
6. **Styles AI Agents MUST NOT Invent**: Explicit negative constraints forbidding arbitrary colors and unlisted fonts.
7. **Extraction Confidence & Source Evidence**: Reliability scores and verification status.

### Cursor IDE (`.cursorrules`)
Generates prompt directives tailored for Cursor:

```bash
npx styleprobe https://radix-ui.com -f cursor -o .cursorrules
```

Includes system directives instructing Cursor to use exact CSS variables (`var(--primary)`, `var(--background)`) and avoid hallucinated grays or Tailwind default breakpoints.

### Autonomous Agents (`AGENTS.md`)
Generates standardized instructions for OpenAI Codex, Antigravity, and GitHub Copilot:

```bash
npx styleprobe https://resend.com -f agents -o AGENTS.md
```

### Export All Agent Contexts Simultaneously
Generates all three agent files plus `DESIGN.md` in a single command:

```bash
npx styleprobe https://linear.app -f all-agents
```
This generates:
- `CLAUDE.md`
- `AGENTS.md`
- `.cursorrules`
- `DESIGN.md`

## 3. Design System & Frontend Framework Exporters

### Tailwind CSS v4 (`@theme` Block)
Generates modern Tailwind v4 configuration with detected site breakpoints and border radii:

```bash
npx styleprobe https://vite.dev -f tailwind-v4 -o theme.css
```

```css
/* Modern Tailwind v4 Theme Configuration - Generated by styleprobe */
@import "tailwindcss";

@theme {
  --color-background: #ffffff;
  --color-surface: #f6f6f7;
  --color-primary: #646cff;
  --color-text-primary: #213547;
  --color-border: #e2e2e3;

  --font-sans: "Inter", sans-serif;

  --breakpoint-md: 768px;
  --breakpoint-lg: 1024px;
  --breakpoint-xl: 1280px;

  --radius-brand-1: 8px;
}

@layer base {
  .dark {
    --color-background: #1b1b1f;
    --color-surface: #202127;
    --color-primary: #747bff;
    --color-text-primary: #fffff5;
    --color-border: #2e2e32;
  }
}
```

### Tailwind CSS v3 (`tailwind.config.js`)
Generates a complete CommonJS `tailwind.config.js` mapping custom site screens:

```bash
npx styleprobe https://tailwindcss.com -f tailwind -o tailwind.config.js
```

### shadcn/ui (`globals.css` HSL Tokens)
Generates dual-theme space-separated HSL tokens (`H S% L%`) compatible with `shadcn/ui`:

```bash
npx styleprobe https://supabase.com -f shadcn -o globals.css
```

```css
@layer base {
  :root {
    --background: 0 0% 100%;
    --foreground: 222 47% 11%;
    --card: 210 40% 98%;
    --primary: 153 60% 53%;
    --border: 214 32% 91%;
    --radius: 0.5rem;
  }
  .dark {
    --background: 222 47% 7%;
    --foreground: 210 40% 98%;
    --card: 222 47% 11%;
    --primary: 153 60% 53%;
    --border: 217 33% 17%;
  }
}
```

### Figma & W3C Design Tokens (DTCG JSON)
Generates a standardized Design Tokens Community Group (DTCG) JSON token tree:

```bash
npx styleprobe https://primer.style -f figma -o tokens.json
```

### Standard CSS Custom Properties (`:root` & `.dark`)
Generates pure CSS variables with responsive layout variables:

```bash
npx styleprobe https://github.com -f css -o variables.css
```

## 4. Multi-Page Graph Crawling

Real websites have distinct styles on documentation or pricing pages. Crawl subpages to aggregate styling rules:

```bash
# Crawl homepage and immediate links (depth 2), up to 10 pages
npx styleprobe https://vite.dev --depth 2 --max-pages 10 -o DESIGN.md

# Follow RFC 9309 robots.txt rules and XML sitemaps automatically
npx styleprobe https://linear.app --depth 2 --max-pages 5
```

---

## 5. Brand Asset & SVG Harvester

Harvest inline brand marks, SVGs, and vector icons into a local directory:

```bash
npx styleprobe https://vite.dev --assets ./brand-assets
```
Creates:
```
brand-assets/
  ├── asset-1-logo.svg
  ├── asset-2-icon.svg
  └── asset-3-mark.svg
```

## 6. Programmatic TypeScript / Node.js API

Use `styleprobe` as a library in your Node.js or TypeScript projects:

```typescript
import { extractDesignTokens } from 'styleprobe';
import { 
  formatToClaudeMd, 
  formatToTailwindV4, 
  formatToFigmaTokens 
} from 'styleprobe';
import * as fs from 'node:fs/promises';

async function generateDesignContext(targetUrl: string) {
  // 1. Extract design tokens with responsive probing
  const tokens = await extractDesignTokens(targetUrl, {
    depth: 1,
    maxPages: 1,
    timeout: 30000
  });

  console.log(`Extracted ${tokens.colors.palette.length} color tokens`);
  console.log(`Confidence score: ${tokens.confidence?.overallScore}% (${tokens.confidence?.level})`);

  // 2. Format into AI instructions and framework configs
  const claudeInstructions = formatToClaudeMd(tokens);
  const tailwindTheme = formatToTailwindV4(tokens);
  const figmaJson = formatToFigmaTokens(tokens);

  // 3. Save files
  await fs.writeFile('CLAUDE.md', claudeInstructions, 'utf-8');
  await fs.writeFile('theme.css', tailwindTheme, 'utf-8');
  await fs.writeFile('tokens.json', figmaJson, 'utf-8');
}

generateDesignContext('https://linear.app');
```

## 7. Extraction Confidence & Verification

Every extraction produces a `DesignSystemConfidenceReport`:

```typescript
interface DesignSystemConfidenceReport {
  overallScore: number;         // 0 to 100 (e.g. 97)
  level: 'high' | 'medium' | 'low';
  colorConfidence: 'high' | 'medium' | 'low';
  typographyConfidence: 'high' | 'medium' | 'low';
  responsiveConfidence: 'high' | 'medium' | 'low';
  componentConfidence: 'high' | 'medium' | 'low';
  evidenceSummary: {
    cssVariablesFound: number;
    computedRolesMatched: number;
    mediaQueriesDetected: number;
    componentsSampled: number;
  };
}
```

This ensures coding agents and developers have transparent visibility into where every token originated and whether it is backed by an explicit CSS custom property or computed DOM sampling.
